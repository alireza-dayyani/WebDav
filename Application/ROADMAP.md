# Inkstone roadmap

The current application combines a Vue frontend, a .NET 10 account and storage API, and the Rust browser editor.

Current foundation: private accounts, saved native documents, automatic saves, conflict checks, and local format exports.

Next work: multilingual UI and contextual RTL writing, server-side upload/download, documented standalone API, and development API exploration.

Deployment configuration, sharing, revision history, and account recovery are later work. Engine format and rendering behavior is documented in docs; inherited parity assessments do not establish hosted application readiness.
